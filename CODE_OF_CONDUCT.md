# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

In short: be respectful, welcoming, and constructive. Harassment and discrimination of any kind are
not tolerated. The full text is available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

Report unacceptable behavior to **conduct@otp.com**. Maintainers will review and respond to every
report and will keep the reporter's identity confidential.
